# Notification

A Flutter application with a Home page and a Notification page, where notifications are loaded dynamically from an API.

## Features
- Home screen UI
- Notification screen
- Fetch notifications using API call
- Display notification list in UI

## Tech Stack
- Flutter
- Dart
- REST API

## Project Structure
- `lib/main.dart` – App entry point
- `lib/home.dart` – Home screen
- `lib/notification_screen.dart` – Notification screen with API integration
- `assets/` – App images and resources

## Getting Started
1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run`
